Assignment 2 
web scripting programming - express portfolio site 

This personal portfolio website was developed using Node.js, ExpressJS, EJS and Font awesome. With the use of Github, render and also visual studio i was able to complete this assignment and also have a working portfolio. 

Project outline 
the portfolio contains four main pages which are home, about me, projects and contact me page.
home - it contains an introduction and also various navigation to the rest of the portfolio.
about me - it contains information about me and also lists skills.
projects - it contains sample projects and activities completed by me in the past.
contact me - it contains contact form with name, email and message. 

FOCUS OF PROJECT 
This project was made to allow shared navigation and footer on every page.
